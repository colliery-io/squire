# Icon Guidelines

Version: 1.0

Purpose:

This document defines the visual language for all icons used throughout Squire.

All icon generation prompts must follow this guide in conjunction with:

* color-palette.md
* materials.md

The goal is to ensure every icon feels like it belongs to the same product, regardless of when it was generated.

---

# Design Philosophy

Icons should feel like objects from a child-friendly fantasy adventure.

Think:

* D&D for Kids
* Hearthstone readability
* Disney-level clarity
* Storybook charm

Icons should be:

* Readable
* Friendly
* Physical
* Tangible

Avoid:

* Dark fantasy
* Excessive magic
* Aggressive styling
* Visual clutter

---

# Core Style

Target Style:

Hearthstone readability with Disney restraint.

This means:

* Strong silhouettes
* Exaggerated forms
* Clean rendering
* Controlled detail density

Icons should immediately communicate their purpose.

Children should recognize the object before reading any text.

---

# Canvas Requirements

Size:

1024 × 1024

Background:

Transparent

Composition:

Single object

Centered

No text

No decorative backgrounds

No scene composition

---

# Object Philosophy

Icons represent things.

Not scenes.

Not stories.

Not environments.

Examples:

Good:

* Coin
* Gem
* Scroll
* Chest
* Book
* Crown

Bad:

* Coin pile
* Treasure room
* Scroll on table
* Character holding chest

One icon equals one primary object.

---

# Shape Language

All icons should use:

* Rounded forms
* Friendly curves
* Thick silhouettes
* Exaggerated proportions

Avoid:

* Sharp spikes
* Thin elements
* Aggressive points
* Needle-like details

When in doubt:

Round it.

---

# Readability Requirements

Icons must remain recognizable at:

64 × 64 pixels

Preferred:

32 × 32 pixels

Silhouette Test:

Convert the icon to a black silhouette.

If the object remains recognizable:

Pass.

If recognition depends on internal details:

Fail.

---

# Visual Complexity

Target Complexity:

Medium

Composition should generally contain:

70% Primary Forms

20% Secondary Forms

10% Small Details

Examples:

Coin:

Primary:
Coin body

Secondary:
Star engraving

Details:
Surface accents

Avoid excessive ornamentation.

---

# Rendering Style

Style:

Stylized Semi-Realistic

Objects should feel:

* Physical
* Tangible
* Touchable

Objects should not feel:

* Cartoon-flat
* Photorealistic
* Hyper-rendered

The goal is:

"Illustrated game asset"

not

"Product photograph"

---

# Lighting

Primary Light Source:

Upper Left

Secondary Fill:

Lower Right

All icons must follow this lighting direction.

Consistent lighting creates visual cohesion.

---

# Edge Treatment

Use:

Soft painted edges

Subtle edge definition

Internal contrast

Avoid:

* Thick black outlines
* Comic outlines
* Sticker-style borders

Icons should feel painted rather than drawn.

---

# Material Rendering

Follow materials.md.

Materials should communicate meaning.

Examples:

Parchment:
Readable

Wood:
Structural

Gold:
Progress

Gem:
Achievement

Purple:
Hierarchy

Never use materials merely because they look attractive.

Material choice should reinforce meaning.

---

# Magic and Fantasy Effects

Fantasy should come from the object itself.

Not from magical effects.

Allowed:

* Decorative engravings
* Fantasy craftsmanship
* Heraldic motifs
* Storybook styling

Avoid:

* Floating particles
* Magical glows
* Energy trails
* Arcane runes
* Spell effects

Examples:

Good Coin:
Beautifully crafted gold coin.

Bad Coin:
Glowing enchanted coin.

Good Ruby:
Polished ruby.

Bad Ruby:
Levitation crystal emitting magical energy.

---

# Scale and Occupancy

Icons should occupy approximately:

70%–80%

of available canvas space.

Avoid:

Tiny objects surrounded by whitespace.

The object should feel substantial.

---

# Shadow Rules

Shadows should be:

* Soft
* Controlled
* Consistent

Purpose:

Ground the object.

Not create dramatic mood.

Avoid:

* Harsh drop shadows
* Long shadows
* Directional spotlight effects

---

# Color Usage

Follow color-palette.md.

Colors should reinforce hierarchy.

Examples:

Gold:
Progress

Green:
Completion

Purple:
Prestige

Orange:
Epic rarity

Avoid introducing colors outside the approved palette without a documented reason.

---

# Asset Consistency Checklist

Before approving any icon:

□ Recognizable at 64px

□ Single primary object

□ Transparent background

□ Upper-left lighting

□ Soft painted edges

□ Medium detail density

□ No unnecessary magic effects

□ Uses approved materials

□ Uses approved color palette

□ Matches existing icon family

If any item fails, revise the asset.

---
