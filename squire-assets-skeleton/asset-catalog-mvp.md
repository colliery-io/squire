# MVP Asset Catalog

Version: 1.0

Purpose:

This document defines the minimum viable visual asset library required to launch Squire.

The MVP catalog focuses on:

- Core application functionality
- Strong visual consistency
- Reusable design language
- Minimal asset maintenance burden

New assets should only be added when a clear product need exists.

# Generation Priority

The following assets establish the visual language and should be generated first.

Phase 1

1. icon_coin_star
2. icon_gem_ruby
3. icon_quest_scroll
4. icon_reward_chest
5. icon_streak_flame

These assets become the reference set for all future icon generation.

---

Phase 2

1. Category Assets
2. Navigation Assets
3. Heraldry Assets

These assets establish broad application coverage.

---

Phase 3

1. Badge Assets
2. Decorative Assets
3. Banner Assets

These assets reinforce progression and visual identity.

---

Phase 4

1. Texture Assets
2. Illustration Assets

These assets complete the visual system and support advanced UI presentation.

---

# Catalog Governance

This catalog should remain intentionally small.

New assets should only be introduced when:

- Required by a new feature
- Repeatedly requested by product needs
- Unable to be represented by existing assets

Preference should always be given to reuse over expansion.

Consistency is more valuable than quantity.
